# 🎮 C/C++ 小游戏合集

个人学习 C/C++ 期间编写的小游戏项目合集,共 7 款小游戏,主要使用 **C / C++** 与 **raylib** 开发,IDE 为 Visual Studio 2022。

## 📁 项目列表

| 目录 | 游戏 | 语言 | 说明 |
|---|---|---|---|
| [泰拉瑞亚复刻](./泰拉瑞亚复刻/) | 泰拉瑞亚复刻 | C++ / raylib | 2D 沙盒:无限区块世界、挖掘建造、合成装备、流体模拟、战斗、史莱姆王/克苏鲁之眼 Boss、NPC 与商店、昼夜光照、程序化音效 |
| [跑酷游戏](./跑酷游戏/) | 跑酷 | C++ / raylib | 完整版:障碍物、道具、音效、计分系统,附课程设计报告 |
| [跑酷游戏_改进版](./跑酷游戏_改进版/) | 跑酷(改进版) | C++ / raylib | 早期单文件版本 + 游戏素材 |
| [俄罗斯方块](./俄罗斯方块/) | 俄罗斯方块 | C++ | 经典玩法 + 本地排行榜 |
| [贪吃蛇](./贪吃蛇/) | 贪吃蛇 | C++ | 控制台贪吃蛇 |
| [扫雷](./扫雷/) | 扫雷 | C | 经典扫雷 |
| [猜数游戏](./猜数游戏/) | 猜数字 | C | 入门练习项目 |
| [我的世界复刻](./我的世界复刻/) | 我的世界 | JavaScript | 单文件 HTML5 体素沙盒 |

## 🛠 环境要求

- Visual Studio 2022(或任意支持 C/C++ 的编译器)
- 跑酷游戏、泰拉瑞亚复刻依赖 [raylib](https://www.raylib.com/),可通过 vcpkg 安装:

  ```
  vcpkg install raylib
  ```

## 🚀 运行

用 Visual Studio 打开对应目录下的 `.sln` 解决方案文件,直接编译运行即可。

- `跑酷游戏/课程报告.md` 为跑酷游戏的课程设计报告

- `.vs/`、`x64/`、`Debug/Release`、`save/` 等编译产物与运行时数据不纳入版本控制(见 `.gitignore`)
