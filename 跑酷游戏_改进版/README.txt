跑酷游戏 - 流畅立体版

操作：
ENTER：开始 / 重新开始
W / ↑ / 空格：跳跃，空中再次按下可二连跳
S / ↓：滑铲
A / D / ← / →：左右移动
P：暂停 / 继续
F11：进入或退出全屏

本版升级：
1. 使用 raylib/OpenGL 硬件加速，不再使用容易卡顿的 GDI+ 软件绘图。
2. 开启垂直同步并锁定稳定 60 FPS，右上角会显示实时帧率。
3. 使用固定时间步更新物理，窗口大小变化不会影响游戏速度。
4. 角色与障碍物作为 GPU 纹理绘制，不再每帧处理超大原图。
5. 窗口可自由拖动调整尺寸、最大化，也可按 F11 全屏。
6. 加入真正的二连跳，并在左上角显示剩余跳跃次数。
7. 恢复吃金币过程：金币会成串出现，收集后加分、连击、爆出金色粒子。
8. 恢复并强化逐渐加速：速度会随生存时间持续提升，左上角有 Speed 数值和速度条。
9. 速度越快，障碍和金币节奏越密，速度线也会更明显。
10. 加入远近山体视差、透视地面、速度线和多层云朵。
11. 角色会随上升和下落倾斜，并带有立体投影和动态地面阴影。
12. 起跳、二连跳、落地、吃金币和碰撞时会产生粒子及轻微镜头震动。
